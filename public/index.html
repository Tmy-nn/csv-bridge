A deliberate integration boundary

The output contract is sku, name, quantity, unit_price, currency. Required fields, numeric formats, supported currencies and duplicate SKUs are checked before download. A single invalid row blocks the export.

Formula-like text is prefixed with an apostrophe in the exported file. Spreadsheet import settings can reinterpret CSV, so inspect the result before using it in another system. This demo does not connect to an ERP or write to StockFlow.

Source text and results live in memory until this tab is reloaded. The hosting provider still receives ordinary page requests; CSV content is never sent by this app.
